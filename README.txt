# Pipe ID Measure

An iPhone-friendly offline web app for drainage/UV lining work.

## Use
Open `index.html` in Safari. For the best experience, host the folder on a simple HTTPS web host, open it on the iPhone, then use Safari's Share -> Add to Home Screen.

## Current functions
- Convert measured internal circumference to internal diameter.
- Supports mm, cm, m and inches.
- Reverse calculation: diameter to circumference.
- DN reference table.
- Saves the last 20 measurements locally on the phone.
- Works offline after the first load.

The next version could add:
- circumference tape/diameter entry presets for 150/160/170/180/225/250/300 mm pipes;
- liner-length and patch calculator;
- ovality calculation;
- photo/measurement notes;
- ARKit camera measurement for estimating pipe dimensions.
